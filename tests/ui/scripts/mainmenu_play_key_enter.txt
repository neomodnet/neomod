# the keydown half of UI::hiddenAtPress on the PLAYABLE fixture: Enter on the expanded
# mainmenu opens the songbrowser (2nd visit, bVisible flips immediately), and the same
# keydown used to continue below MainMenu into SongBrowser::onKeyDown -> the carousel's
# Enter = playSelectedDifficulty, starting the selected map straight from the mainmenu.
# NO ui_trace (see play_modselector_dance: play-start timing is not sim-deterministic), so
# this is assertion-only: the songbrowser must still be visible after the wait (in-play would
# hide it under the gameplay composite).
options_save_on_back 0

@wait 30

@wait 5
ui_assert screen_active mainmenu 1

ui_assert visible mainmenu_singleplayer 1
sendkey Return
@wait_secs 5
ui_assert screen_active songbrowser 1
ui_assert visible songbrowser 1
exit
